# Shared Jev → AGY_MODEL evidence gate and headless workflow runner

> **Routing Precedence Notice:** Current routing policy in [routing.md](routing.md) **explicitly supersedes** conflicting legacy provider lists, wait-only instructions, and absolute local-Codex prohibitions **below**; all unrelated security, quant, retry, financial, and reviewer rules remain in force. External-first (`WORKFLOW_WORKER=agy|devin|opencode|zai|openrouter`, default `agy`) allows coordinator fallback to permitted smaller/free CLIs and direct free APIs (`zai`, `openrouter` `:free`) on clean availability/quota/auth/timeout errors (counted in the 2-extra-execution ledger, 100k/180s), then current main Codex last-resort outside `run_workflow.py` with Jev 1.13.0, High, and fresh final review.

`scripts/run_workflow.py` and `scripts/jev_review_gate.py` provide stdlib-only orchestration and evidence gating. Neither authenticates arbitrary logs, proves financial mathematics, or authorizes live actions.

**Model & context selection:** `AGY_MODEL` (per invocation; the `agy` worker and always the fresh independent `--effort high` `agy` reviewers) accepts only `claude-opus-5-5-high` or `gemini-4-argon-high` (default when unset/empty). Any other value is `BLOCKED` before any `agy` or Jev call. `WORKFLOW_WORKER=agy|devin|opencode` (`agy` default, `devin`, or `opencode` with explicit exact `OPENCODE_MODEL=<providerID>/<modelID>` and optional `OPENCODE_BIN`, free models only—no paid fallback, hooks, background polling, automatic runtime switching, or account/key/billing changes; `opencode/deepseek-v4.1-flash-free` and `opencode/beam-free` reported `Free usage limit reached` and are not claimed available, so wait when exhausted; anything else `BLOCKED` before calls) selects the worker. `WORKFLOW_CONTEXT=lean|compact|full` (candidate default `lean`, `compact`/`full` retained; anything else `BLOCKED` before calls) selects prompt and per-session schema framing: `lean` and `compact` trim boilerplate instructions while always retaining the verbatim task contract and full contents of all declared `--scope` source files, and `lean` adds per-session Devin `disabled_tools` (including `web_search`) and requires ATIF `agent.tool_definitions` to be a well-formed unique-name subset of the 5 remaining mandatory tools (`mcp_call_tool`, `mcp_list_servers`, `mcp_list_tools`, `mcp_read_resource`, `skill`; schema hiding is not tool authorization and the remaining 5 tools stay denied by `permissions.deny` and the `exit 2` hook; export schema count/names/chars and system/skill-catalog chars are recorded for benchmarks while `usage` fields remain unchanged). Coordinator intake uses a single bounded seam, `rg`/AST targeted reads instead of broad repo dumps, native quota/auth queries (`agy --print /usage`) instead of unnecessary model probes, no transparent CLI hooks or account/key rotation, and returns the compact `proof-pack.txt` to ChatGPT. Reports keep identities separate (`worker_provider`/`worker_model`/`worker_effort`, `reviewer_model`/`reviewer_effort`, `context_mode`); legacy `worker_and_reviewer_model`/`effort` are set only for `agy` workers (null on Devin and OpenCode runs). `usage_totals.gemini` is a legacy key covering only `agy` usage; Devin ATIF counters appear only in `usage_totals.devin` and OpenCode counters appear only in `usage_totals.opencode` with `total_tokens = input_tokens + output_tokens + reasoning_tokens + cache_read_tokens + cache_write_tokens` (all five categories disjoint in OpenCode 1.19.5; optional native `tokens.total` must equal this sum).

**Devin & OpenCode worker packets:** For Devin, `worker` = `{provider: "devin", model: "swe-1-6-slow", exit_code: 0, proof_status: "VERIFIED", response, tool_denied: false, tool_calls: 0}` with no `status`/`effort`/`permission_mode`, and `evidence.worker_proof` requires `provider`, `actual_generation_model`, `agent_model_name` (`SWE-1.6 Slow`), `permission_mode: "Normal"`, `schema_version: "ATIF-v1.7"`, `exit_code: 0`, `tool_calls: 0`, `tool_denied: false`, `stdout_matches_export: true`, `session_id`, and no `actual_init_model`/`status`/`effort`. For OpenCode, `worker` = `{provider: "opencode", requested_model, model, provider_id, model_id, exit_code: 0, export_exit_code: 0, proof_status: "VERIFIED", response, tool_denied: false, tool_calls: 0}` and `evidence.worker_proof` requires `provider: "opencode"`, matching `requested_model`/`actual_generation_model`/`provider_id`/`model_id`, `exit_code: 0`, `export_exit_code: 0`, `tool_calls: 0`, `tool_denied: false`, `stream_matches_export: true`, `session_id`, `generation_steps > 0`, `finish_reason`, `config_proof_status: "VERIFIED"`, 64-hex config/stdout/export/response SHA-256 digests, verified `usage` with `total_tokens == input_tokens + output_tokens + reasoning_tokens + cache_read_tokens + cache_write_tokens`, and no `actual_init_model`/`status`/`effort`/`permission_mode`. Any mismatch blocks before Jev.

## One-command headless workflow (`scripts/run_workflow.py`)

```bash
python3 scripts/run_workflow.py [packet.txt] \
  --id sample-1 --kind task \
  --workspace /path/to/workspace \
  --scope port_spec.py tests/test_port_spec.py \
  --verify-cmd "python3 -B -m unittest discover -s tests -v" \
  --key-slot 1 --output-dir /outside/workspace/run-1
```

- **Worker execution & permissions:** Generates task-local `worker-settings.json` with `toolPermission: "request-review"`, `allowNonWorkspaceAccess: false`, explicit `write_file`/`edit_file` rules for declared scope paths, explicit `command` rules for `--verify-cmd`, and denies `read_url`, `execute_url`, `mcp`, and subagent delegation.
- **Metadata & fail-closed checks:** Requires `agy` exit 0, `init.model ==` the resolved selected model, `init.permission_mode == "request-review"` (missing blocks), `init.effort == "high"` when present (if omitted by CLI, records verification via `--effort high` plus the `-high` model slug), `result.status == "SUCCESS"` (a timeout `finished_reason` such as `print_timeout` blocks even with `SUCCESS`), non-empty response, and no tool denial or timeout. Fails closed as `BLOCKED` on any violation. Devin worker proof is validated separately (see `scripts/devin_worker.py` and the task-runner skill).
- **Mechanical checks & rework:** Snapshots workspace files before execution, verifies changed paths stay inside `--scope`, runs `--verify-cmd` (requiring exit 0 and `passed > 0`), and checks whitespace via `git diff --no-index --check`. On mechanical check failure or reviewer `REJECT`, sends a concise rework prompt (`<=400` tokens) back to the worker (resuming the worker conversation via `--conversation <id>` by default) for at most **two unsuccessful rework loops** (`--max-reworks`, 0..2).
- **Optional RTK pytest postprocessing (`filter_verification_output`):** Runs `rtk pipe -f pytest` only on verified passing supported pytest output (`exit_code == 0`, `passed > 0`, no unittest/Node/Go markers or `FAILED` lines) when `rtk` is installed, exits 0 within timeout, and produces a filtered passed count matching `raw_passed`. Unsupported runners (such as `unittest`), failing/zero-count runs, missing `rtk`, timeouts, nonzero exits, empty/`No tests collected`/error output, or count mismatches fall back to `raw_output`. Writes redacted `verification-raw.txt` and `verification-filtered.txt` artifacts plus SHA-256 digests (`raw_sha256`, `filtered_sha256`) and byte/char savings. Raw exit code, raw passed count, and full reviewer diff/evidence remain authoritative.
- **Task-wide retry ledger (coordinator-enforced, not automatic code):** 2 extra worker executions after the initial one, shared by internal reworks and cross-run/cross-model restarts (only after real quota/auth/availability `BLOCKED` in coordinator order `AGY_MODEL` -> `devin` -> `opencode`; mismatch/denial stay terminal `BLOCKED`, and exhausted `AGY_MODEL` reviewer quota remains `BLOCKED`), never reset. Subtract each run's `rework_loops`; before a new invocation reserve 1, STOP if none remains, then pass `--max-reworks REMAINING`. Example: quota-blocked initial run (0 reworks) -> restart with `--max-reworks 1`; any further restart needs `--max-reworks 0` and remaining budget. Retries keep the original task snapshot and review the aggregate change; `BLOCKED` if original evidence cannot be established.
- **Cumulative usage accounting:** Resumed `agy` conversations report cumulative counters. `run_workflow.py` retains `raw_terminal_usage` snapshots and computes per-step deltas without double counting. `cache_read_tokens` is reported separately from `input_tokens` and `total_tokens`.
- **Default native ChatGPT final review (`--chatgpt-review {off,baseline,scoped}`, global CLI default `scoped`; `scripts/chatgpt_review.py`):** Enabled by default as `scoped` across every repo using this shared global CLI without a manual flag (`--chatgpt-review off` is an explicit override; `baseline` is for explicit paired measurement only; no hooks, repo-wide rewrites, or forced settings); preflight requires `--output-dir` outside `--workspace` before the worker call, runs `run_workflow` once unchanged, and only on native pipeline `PASS` runs one fresh ephemeral read-only Codex CLI review (`--ask-for-approval never exec --ephemeral --skip-git-repo-check --sandbox read-only --model gpt-6.1-sol -c model_reasoning_effort="max"`) using existing ChatGPT auth in an exclusive sibling output directory (`<output-dir>-chatgpt-review`). `scoped` narrows per-call catalog overhead (`features.{shell_tool,apps,multi_agent,browser_use,computer_use,image_generation,view_image}=false`, `web_search="disabled"`, configured MCP servers disabled, unrelated `SKILL.md` paths disabled via per-file `skills.config` while keeping all mandatory Superpowers `7.0.1` and workflow skills `antigravity-task-runner`, `antigravity-sol-quant-runner`, `jev`), preloads `using-superpowers` and `verification-before-completion` via stdin, and retains the full focused diff, raw test verification output, full worker handoff, and coordinator-parsed worker and `agy` reviewer proofs (`reviewer-N-invocation.json`, `reviewer-N.stdout.jsonl`, `reviewer-N-result.json`) with no hooks, auth, endpoint, config, or permission loosening. Leaves `workflow-result.json` and `proof-pack.txt` untouched and writes `workflow-final-result.json` (cannot `PASS` unless both pipeline and native ChatGPT review `PASS`; skips GPT and propagates non-`PASS` when the pipeline does not pass; any helper error/tool event/missing usage fails closed as `BLOCKED`). `all_in_total_tokens` sums Codex `input_tokens + output_tokens` + Devin `total_prompt_tokens + total_completion_tokens` + OpenCode `input_tokens + output_tokens + reasoning_tokens + cache_read_tokens + cache_write_tokens` (OpenCode 1.19.5 `tokens.input` excludes `cache.read`/`cache.write` and `tokens.output` excludes `reasoning`, so all five disjoint categories are summed once) + `$jev` `input_tokens + output_tokens` + `agy` `input_tokens + cache_read_tokens + output_tokens`; Codex/AGY cached/reasoning subsets (`cached_input_tokens`, `cache_write_input_tokens`, `reasoning_output_tokens`, `thinking_tokens`) and Devin's separate `total_cached_tokens` are never counted twice, and partial/missing/unaccounted counters stay `'unknown'`. Measures the headless review stage + provider I/O only (Desktop chat history/preparation is separate; no claim to shorten it or to attest backend-resolved model beyond CLI flags). ChatGPT never writes code or replaces `agy`, quant dual review, or a required stronger reviewer. Consume `workflow-final-result.json` or the `--print-pack` combined summary rather than polling raw logs.
- **Outputs & exit codes:** Writes `workflow-result.json` and compact `proof-pack.txt` (plus `workflow-final-result.json` unless `--chatgpt-review off` is passed). Exit codes: `0` PASS, `1` REJECT, `2` BLOCKED, `3` PENDING_REVIEW.

## Standalone Jev → AGY_MODEL review gate (`scripts/jev_review_gate.py`)

```bash
python3 scripts/jev_review_gate.py packet.json --output-dir NEW_DIR --key-slot 1
```

### Packet input schema

```json
{
  "schema_version": 1,
  "id": "sample-1",
  "kind": "task",
  "objective": "Fix the bounded parser seam",
  "worker": {
    "model": "gemini-4-argon-high",
    "effort": "high",
    "exit_code": 0,
    "status": "SUCCESS",
    "response": "Nonempty actual worker response",
    "tool_denied": false
  },
  "checks": [
    {"kind": "tests", "command": "python3 -m unittest", "exit_code": 0, "passed": 8, "output": "Actual output"},
    {"kind": "scope", "command": "compare source snapshots", "exit_code": 0, "output": "Actual changed paths"},
    {"kind": "whitespace", "command": "git diff --check", "exit_code": 0, "output": "exit 0, no whitespace errors"}
  ],
  "evidence": {
    "focused_diff": "Actual unified diff",
    "verification_output": "Actual commands, output and exit codes",
    "summary": "Bounded change and residual limitations",
    "source_hashes": {"port_spec.py": "<sha256>"}
  },
  "open_questions": []
}
```

For `kind: "quant"`, include `quant_contract` with non-empty `data_provenance`, `friction`, `causality`, and `parity` strings (placeholders like `unknown`, `N/A`, or `tbd` block). Optional `min_reviewers` (`1..4`) can raise the reviewer count, never lower the quant minimum of 2. Requiring a stronger model is a separate obligation; a fresh context of the selected `AGY_MODEL` does not qualify as a stronger tier.

### Triage efficiency, credential safety, and routing

- **Targeted Jev state (`build_jev_state`):** Sends Jev (`jev-1.13.0`) only `objective`, `kind`, `summary`, `verification_output`, compact check statuses, `open_questions`, `quant_contract` (if quant), and cryptographic hashes (`diff_sha256`, `packet_sha256`, `source_hashes`) linking the exact reviewed code, omitting raw diff bodies.
- **Deduplicated reviewer payload (`build_reviewer_payload`):** Sends each fresh selected-model `--effort high` reviewer the full `evidence` (`focused_diff`, `verification_output`, `summary` labelled a short excerpt, `full_worker_handoff`, compact `worker_proof` parsed by the coordinator from CLI init/result metadata, `source_workspace`, `source_hashes`), check metadata, `open_questions`, `jev` triage, and `route`, omitting duplicated `worker.response`, raw logs and `checks[].output`. The gate blocks if `full_worker_handoff` differs from the verified response or exceeds 4000 chars, or if `worker_proof` disagrees with the selected model, `request-review`, success or no-denial. Reviewer cwd is a separate read-only artifact folder by design; paths/hashes refer to `source_workspace`. Findings must hold only blocking defects; observations belong in `residual_risk`.
- **Credential redaction:** Blocks and redacts real API credentials, authentication headers and sensitive credential assignments while allowing ordinary source identifiers, type hints and pure-reference expressions. Actual secret values remain blocked.
- **Routing (`jev-review-v1`):** Requires `adequate` label, confidence `>=0.85`, margin `>=0.20`, concern `<0.15`, and no `open_questions` for `standard_review`; otherwise routes to `escalated_review`. Both keep mandatory independent reviewers (1 task, 2 quant) with distinct `conversation_id`s, `request-review` permissions, and no tool calls. `PASS` requires empty `findings` and explicit resolutions for all `open_questions`.
