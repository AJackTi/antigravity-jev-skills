# Antigravity + Jev Skills

External workers implement and fix code; Jev triages evidence; independent High reviewers and a read-only Codex final review check the result.

- `antigravity-task-runner`: bounded engineering tasks.
- `antigravity-sol-quant-runner`: quant and risk review.
- `jev`: typed decisions and evidence triage.

```bash
git clone https://github.com/AJackTi/antigravity-jev-skills.git
cd antigravity-jev-skills
python3 -B install.py
python3 -B install.py --install
```

Installation registers symlinks, preserves existing directories, and bundles no credentials. Keep this folder in place. See [INSTALL.md](INSTALL.md) for setup, routing, and a sample task.
